# EnterpriseUI.Security

Security contracts and services for EnterpriseUI applications.

## What it provides

- Authentication, authorization, identity, and permission abstractions.
- Secure application service boundaries for EnterpriseUI workflows.
- Integration points for host-specific security providers.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Security --version 1.2.0
```

Configure the host application's identity and secret management services. NuGet restores the EnterpriseUI dependencies declared by this package.
