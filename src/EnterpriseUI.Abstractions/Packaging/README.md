# EnterpriseUI.Abstractions

Core contracts and platform-neutral abstractions shared by EnterpriseUI packages.

## What it provides

- Component, lifecycle, theming, accessibility, and service contracts.
- Stable interfaces for implementing EnterpriseUI platform adapters.
- A small dependency surface for libraries that integrate with EnterpriseUI.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Abstractions --version 1.2.0
```

Use this package when implementing integrations or libraries against EnterpriseUI contracts. NuGet restores any declared EnterpriseUI dependencies automatically.
