# EnterpriseUI.Reporting

Report definition, layout, rendering, and preview services for EnterpriseUI.

## What it provides

- Report bands, groups, data sources, expressions, and calculated fields.
- Designer, viewer, pagination, export, and print integration contracts.
- Structured reporting workflows for operational and analytical applications.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Reporting --version 1.2.0
```

Combine this package with EnterpriseUI.Exporting, EnterpriseUI.Documents, or EnterpriseUI.Printing as needed. NuGet restores declared dependencies automatically.
