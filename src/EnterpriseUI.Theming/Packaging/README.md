# EnterpriseUI.Theming

Theme tokens, palettes, styles, and runtime theming services for EnterpriseUI.

## What it provides

- Fluent, Material, Bootstrap, Office, and modern theme foundations.
- Design tokens for colors, typography, spacing, metrics, and states.
- Runtime theme switching and high-contrast integration contracts.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Theming --version 1.2.0
```

Use a platform adapter to apply theme values to concrete controls. NuGet restores the EnterpriseUI dependencies declared by this package.
