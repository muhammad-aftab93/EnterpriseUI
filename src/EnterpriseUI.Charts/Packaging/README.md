# EnterpriseUI.Charts

Charting models and rendering-independent chart services for EnterpriseUI.

## What it provides

- Line, spline, area, bar, column, pie, donut, and candlestick series.
- Heat maps, sparklines, range selection, and multi-series data models.
- Shared axes, legends, formatting, interaction, and data binding contracts.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Charts --version 1.2.0
```

Use a platform adapter such as EnterpriseUI.WinForms for visual controls. NuGet restores the EnterpriseUI dependencies declared by this package.
