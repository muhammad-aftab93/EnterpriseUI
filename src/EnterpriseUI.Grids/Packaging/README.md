# EnterpriseUI.Grids

Data grid and data presentation components for EnterpriseUI.

## What it provides

- Virtualized, typed, hierarchical, pivot, tree-list, card, and list views.
- Sorting, grouping, filtering, paging, selection, editing, and summaries.
- Large-data workflows designed for responsive enterprise applications.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Grids --version 1.2.0
```

Pair this package with EnterpriseUI.Data and a platform adapter such as EnterpriseUI.WinForms. NuGet restores declared dependencies automatically.
