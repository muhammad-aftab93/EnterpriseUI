# EnterpriseUI.Gauges

Gauge and telemetry visualization models for EnterpriseUI.

## What it provides

- Radial, linear, digital, and bullet gauges.
- Threshold ranges, indicators, scales, labels, and animated values.
- Reusable KPI visualization contracts for platform adapters.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Gauges --version 1.2.0
```

Use a supported platform adapter for concrete gauge controls. NuGet restores the EnterpriseUI dependencies declared by this package.
