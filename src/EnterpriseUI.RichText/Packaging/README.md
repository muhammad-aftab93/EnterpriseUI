# EnterpriseUI.RichText

Rich text editing and document formatting services for EnterpriseUI.

## What it provides

- Rich text documents, paragraphs, runs, styles, tables, and selections.
- Editing commands, formatting state, and import/export integration points.
- Platform-neutral contracts for rich text editor controls.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.RichText --version 1.2.0
```

Use a supported platform adapter for concrete editor controls. NuGet restores the EnterpriseUI dependencies declared by this package.
