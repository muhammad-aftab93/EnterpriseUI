# EnterpriseUI.AI

AI-assisted controls and services for EnterpriseUI applications.

## What it provides

- Reusable prompt, chat, and smart interaction models.
- AI service abstractions that can be connected to an application provider.
- Shared state and presentation primitives for AI-enabled workflows.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.AI --version 1.2.0
```

Configure the application-specific AI provider and credentials outside source control. NuGet restores the EnterpriseUI dependencies declared by this package.
