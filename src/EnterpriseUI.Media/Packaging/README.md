# EnterpriseUI.Media

Media, image, camera, and interactive media services for EnterpriseUI.

## What it provides

- Image editing and display models.
- Webcam, signature, virtual keyboard, and media interaction primitives.
- Shared media contracts for desktop and platform adapters.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Media --version 1.2.0
```

Use a supported platform adapter for concrete media controls. NuGet restores the EnterpriseUI dependencies declared by this package.
