# EnterpriseUI.Core

Foundational runtime primitives for the EnterpriseUI component platform.

## What it provides

- Shared component lifecycle, events, services, and state primitives.
- Common MVVM, licensing, telemetry, and configuration contracts.
- The base layer used by EnterpriseUI data, controls, and platform packages.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Core --version 1.2.0
```

Use this package when building EnterpriseUI-compatible libraries or services. NuGet restores its declared dependencies automatically.
