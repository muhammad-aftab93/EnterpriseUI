# EnterpriseUI.Validation

Validation rules, providers, and validation state for EnterpriseUI applications.

## What it provides

- Fluent and data-annotation compatible validation contracts.
- Synchronous and asynchronous rule execution.
- Field, form, and model validation state for editors and workflows.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Validation --version 1.2.0
```

Connect the validation provider to the application or platform-specific editor layer. NuGet restores the EnterpriseUI dependencies declared by this package.
