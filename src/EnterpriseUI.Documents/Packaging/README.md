# EnterpriseUI.Documents

Document processing models and services for EnterpriseUI applications.

## What it provides

- Shared document, page, text, and formatting abstractions.
- Document workflow primitives for office and reporting scenarios.
- Integration points for PDF, rich text, spreadsheet, and print features.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Documents --version 1.2.0
```

Use the specialized EnterpriseUI document packages for concrete formats and platform views. NuGet restores this package's declared dependencies.
