# EnterpriseUI.Layout

Layout, docking, navigation surface, and responsive composition models for EnterpriseUI.

## What it provides

- Panels, split views, groups, tabs, pages, docking, and auto-hide layouts.
- Wizards, breadcrumbs, menus, command bars, and navigation surfaces.
- Serializable layout state for restoring enterprise workspaces.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Layout --version 1.2.0
```

Use a platform adapter for concrete layout controls. NuGet restores the EnterpriseUI dependencies declared by this package.
