# EnterpriseUI.Exporting

Export services and format abstractions for EnterpriseUI data and views.

## What it provides

- Export pipelines for tabular, report, and visual data.
- Shared format, column, styling, and progress contracts.
- Integration points for spreadsheet, document, PDF, and print workflows.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Exporting --version 1.2.0
```

Configure the desired format provider in the application. NuGet restores the EnterpriseUI dependencies declared by this package.
