# EnterpriseUI.Navigation

Navigation models and command surfaces for EnterpriseUI applications.

## What it provides

- Ribbon, menu, command bar, breadcrumb, and backstage models.
- Navigation panes, page navigation, binding navigation, and shortcuts.
- Command routing and state contracts for platform-specific controls.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Navigation --version 1.2.0
```

Use a platform adapter for concrete navigation controls. NuGet restores the EnterpriseUI dependencies declared by this package.
