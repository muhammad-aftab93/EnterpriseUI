# EnterpriseUI.Rendering

Rendering abstractions for EnterpriseUI visual components and documents.

## What it provides

- Drawing, geometry, brushes, fonts, images, and measurement contracts.
- Rendering-independent primitives shared by charts, documents, and controls.
- A boundary for implementing platform-specific rendering backends.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Rendering --version 1.2.0
```

Use this package when implementing a rendering backend or custom EnterpriseUI visual. NuGet restores its declared dependencies automatically.
