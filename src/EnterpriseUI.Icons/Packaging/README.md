# EnterpriseUI.Icons

Icon catalogs and icon rendering abstractions for EnterpriseUI.

## What it provides

- Reusable Fluent, Material, and application icon definitions.
- SVG and font icon source abstractions.
- Theme-aware icon metadata for EnterpriseUI controls and navigation.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Icons --version 1.2.0
```

Use this package with EnterpriseUI navigation, editors, or platform controls. NuGet restores its declared dependencies automatically.
