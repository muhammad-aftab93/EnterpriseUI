# EnterpriseUI.Editors

Reusable editing, input, and interactive text primitives for EnterpriseUI.

## What it provides

- Text, numeric, masked, autocomplete, date, time, and calculator editors.
- Syntax editing, spell checking, signatures, and rich interaction state.
- Validation-aware editor models that can be rendered by platform adapters.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Editors --version 1.2.0
```

Use EnterpriseUI.WinForms or another platform adapter for concrete controls. NuGet restores the EnterpriseUI dependencies declared by this package.
