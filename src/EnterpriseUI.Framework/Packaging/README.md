# EnterpriseUI.Framework

Retained element tree and cascading style rule engine for EnterpriseUI.

## What it provides

- Platform-neutral visual elements, retained layout, and render-tree primitives.
- Cascading style rules, selectors, inherited values, and state-aware styling.
- A foundation for building consistent EnterpriseUI platform adapters.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Framework --version 1.2.0
```

Use this package when implementing custom EnterpriseUI elements, themes, or platform renderers. NuGet restores the EnterpriseUI dependencies declared by this package.
