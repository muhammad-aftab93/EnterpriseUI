# EnterpriseUI.Printing

Printing, print preview, and page layout services for EnterpriseUI.

## What it provides

- Print documents, pages, margins, headers, footers, and pagination models.
- Print preview and printer configuration contracts.
- Integration with reports, PDFs, documents, and platform adapters.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Printing --version 1.2.0
```

Use a supported desktop adapter for native print dialogs and preview controls. NuGet restores declared dependencies automatically.
