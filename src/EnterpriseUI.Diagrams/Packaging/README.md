# EnterpriseUI.Diagrams

Interactive diagram and graph models for EnterpriseUI applications.

## What it provides

- Node, connector, port, group, and graph document models.
- Orthogonal and Bezier routing, snapping, selection, and viewport state.
- Layout and workflow primitives for architecture and process diagrams.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Diagrams --version 1.2.0
```

Use a platform adapter such as EnterpriseUI.WinForms for diagram rendering. NuGet restores its declared dependencies automatically.
