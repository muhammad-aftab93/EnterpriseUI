# EnterpriseUI.Scheduling

Calendar, scheduler, resource, and task planning services for EnterpriseUI.

## What it provides

- Day, week, work-week, month, and timeline scheduling models.
- Recurrence, resources, appointments, reminders, and time zones.
- Gantt and task planning integration points for enterprise workflows.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Scheduling --version 1.2.0
```

Use a supported platform adapter for scheduler and calendar controls. NuGet restores the EnterpriseUI dependencies declared by this package.
