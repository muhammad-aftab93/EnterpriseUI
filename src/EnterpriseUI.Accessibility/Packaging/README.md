# EnterpriseUI.Accessibility

Accessibility services and contracts for EnterpriseUI components.

## What it provides

- Accessibility metadata, roles, states, and navigation support.
- Shared accessibility behavior for EnterpriseUI controls and adapters.
- Platform-neutral accessibility integration points.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Accessibility --version 1.2.0
```

Reference this package when an application or custom control needs EnterpriseUI accessibility support. NuGet restores its declared dependencies automatically.
