# EnterpriseUI.Pdf

PDF viewing, creation, and document integration services for EnterpriseUI.

## What it provides

- PDF document, page, text, annotation, and navigation models.
- Viewer and rendering integration points for platform adapters.
- Printing and export workflows for enterprise documents.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Pdf --version 1.2.0
```

Use a supported platform adapter for concrete PDF viewers and controls. NuGet restores the EnterpriseUI dependencies declared by this package.
