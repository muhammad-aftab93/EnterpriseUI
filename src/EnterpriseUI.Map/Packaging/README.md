# EnterpriseUI.Map

Mapping and geospatial visualization models for EnterpriseUI.

## What it provides

- Map, layer, marker, coordinate, viewport, and interaction models.
- Data-bound map overlays for operational and analytical applications.
- Platform-neutral contracts for map rendering adapters.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Map --version 1.2.0
```

Configure a map provider in the host application and use a supported platform adapter for rendering. NuGet restores declared dependencies automatically.
