# EnterpriseUI.Data

Data access, query, filtering, and virtualization primitives for EnterpriseUI.

## What it provides

- Expression-based filtering, sorting, grouping, and paging.
- Remote data and asynchronous loading contracts.
- Virtualization and observable data models for large datasets.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Data --version 1.2.0
```

Use this package with EnterpriseUI grids, charts, dashboards, or custom data views. NuGet restores its declared dependencies automatically.
