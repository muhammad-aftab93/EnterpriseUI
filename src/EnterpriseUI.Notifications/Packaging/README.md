# EnterpriseUI.Notifications

Desktop alerts, toast notifications, and notification state for EnterpriseUI.

## What it provides

- Toast, alert, notification, and notification-center models.
- Priority, duration, actions, icons, and lifecycle state.
- Platform-neutral contracts for native notification adapters.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Notifications --version 1.2.0
```

Use a supported platform adapter to display notifications. NuGet restores the EnterpriseUI dependencies declared by this package.
