# EnterpriseUI.Dashboard

Dashboard layout and KPI presentation models for EnterpriseUI applications.

## What it provides

- Dashboard surfaces for arranging panels, cards, charts, and operational views.
- KPI and executive summary models suitable for data-driven applications.
- Shared dashboard state and layout services for platform adapters.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Dashboard --version 1.2.0
```

Use a supported platform adapter to render dashboard views. NuGet restores the EnterpriseUI dependencies declared by this package.
