# EnterpriseUI.Workflow

Workflow, state machine, and task orchestration services for EnterpriseUI.

## What it provides

- Workflow definitions, states, transitions, commands, and guards.
- Async execution, persistence, notifications, and workflow history contracts.
- Reusable orchestration primitives for enterprise applications.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Workflow --version 1.2.0
```

Connect persistence and application services through the host application. NuGet restores the EnterpriseUI dependencies declared by this package.
