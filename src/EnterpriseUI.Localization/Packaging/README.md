# EnterpriseUI.Localization

Localization resources and services for EnterpriseUI applications.

## What it provides

- Resource lookup and culture-aware formatting contracts.
- Localized labels, messages, dates, numbers, and validation text.
- Shared localization integration points for EnterpriseUI controls.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Localization --version 1.2.0
```

Register the localization provider appropriate for the host application. NuGet restores the EnterpriseUI dependencies declared by this package.
