# EnterpriseUI.Office

Office document and spreadsheet services for EnterpriseUI applications.

## What it provides

- Spreadsheet, workbook, worksheet, cell, formula, and formatting models.
- Streaming readers and writers for large office documents.
- Integration points for document processing, export, and reporting workflows.

## Requirements

- .NET 8.0 or .NET Framework 4.8.

## Installation

```powershell
dotnet add package EnterpriseUI.Office --version 1.2.0
```

Use the related EnterpriseUI.Documents and EnterpriseUI.Exporting packages for complete workflows. NuGet restores declared dependencies automatically.
