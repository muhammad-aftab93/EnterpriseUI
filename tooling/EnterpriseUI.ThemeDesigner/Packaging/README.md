# EnterpriseUI.ThemeDesigner

Theme design and token authoring tooling for EnterpriseUI.

## What it provides

- Authoring support for colors, typography, metrics, and component states.
- Theme token workflows aligned with EnterpriseUI.Theming.
- Developer tooling for validating and exporting theme definitions.

## Requirements

- .NET 8.0 SDK.

## Installation

```powershell
dotnet add package EnterpriseUI.ThemeDesigner --version 1.2.0
```

Use the designer with EnterpriseUI.Theming and validate generated themes against the target platform adapter.
