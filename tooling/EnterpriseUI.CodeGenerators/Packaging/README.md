# EnterpriseUI.CodeGenerators

Source generators and developer tooling for EnterpriseUI applications.

## What it provides

- Compile-time generation support for EnterpriseUI models and registrations.
- Reusable generator infrastructure for reducing repetitive application code.
- Build-time integration for projects that opt into the generators.

## Requirements

- .NET 8.0 SDK.

## Installation

```powershell
dotnet add package EnterpriseUI.CodeGenerators --version 1.2.0
```

Use the generated APIs documented by the package and keep generator packages as build-time dependencies where appropriate.

## Documentation

See the [repository](https://github.com/muhammad-aftab93/EnterpriseUI) for generator examples and build guidance.
