# EnterpriseUI.TemplateStudio

Project and item template tooling for EnterpriseUI applications.

## What it provides

- Templates for starting EnterpriseUI projects and components.
- Repeatable scaffolding for platform adapters and application features.
- A foundation for extending EnterpriseUI developer workflows.

## Requirements

- .NET 8.0 SDK.

## Installation

```powershell
dotnet add package EnterpriseUI.TemplateStudio --version 1.2.0
```

Use the templates from a development environment and review generated project settings before committing them.
