# EnterpriseUI.VisualDesigner

Visual design and inspection tooling for EnterpriseUI controls and layouts.

## What it provides

- Design-time workflows for composing EnterpriseUI controls and surfaces.
- Inspection and configuration support for themes, layout, and component properties.
- Developer tooling that complements the EnterpriseUI platform adapters.

## Requirements

- .NET 8.0 SDK.

## Installation

```powershell
dotnet add package EnterpriseUI.VisualDesigner --version 1.2.0
```

Use this tooling package in a development environment and pair it with the platform package being designed.
