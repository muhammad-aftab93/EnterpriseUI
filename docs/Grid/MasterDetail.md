## Overview

Expand a customer to see its orders in a nested table. Turn on lazy loading to fetch children on first expansion, or remove the relation to fall back to a property summary.

- Master/detail
- Lazy child loading
- Property summary fallback
- Expand/collapse all
- Search in details

## Architecture notes

Master/detail is a relation whose children appear below the expanded parent as a labelled child table. Without a relation the parent's properties are shown in a summary row.

## Usage guide

var relation = grid.AddRelation("Orders", "Id", "CustomerId", orders, typeof(OrderRow)); relation.LoadChildrenAsync = async (parent, ct) => await api.OrdersAsync(parent, ct);

## Best practices

Define child columns, load children lazily when they are remote, and expand only what users ask for.

## Performance notes

Child lookups are dictionary based; lazy relations fetch only on first expansion and then cache.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

Expanded state is exposed on the row; Alt+Right expands and Alt+Left collapses; the child table's header row is announced with its title.

## Troubleshooting

If expansion shows nothing the relation key types differ or the foreign field is misspelled; if it spins, a lazy loader is still running or failed (see LastError).
