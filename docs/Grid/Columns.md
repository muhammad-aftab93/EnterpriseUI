## Overview

Drag headers to reorder or onto the group panel, drag the edge to resize, double-click the edge for best fit, right-click for pin, hide and the column chooser. Save and restore layouts as JSON.

## Architecture notes

Column state lives on GridColumn and in ColumnLayoutProfile snapshots. The layout engine (GridColumnLayout) turns ordered visible columns into pixel slots in left, scrollable and right zones.

## Usage guide

var json = GridLayoutSerializer.ToJson(grid.CreateLayoutProfile()); grid.ApplyLayoutProfile(GridLayoutSerializer.FromJson(json)). Unknown columns produce warnings instead of exceptions.

## Best practices

Save one layout per user and grid id, store it as JSON, and apply it after columns are defined and before the first load.

## Performance notes

Layout is recomputed per frame from the column list, which is cheap (linear in visible columns). Best fit samples at most a few hundred rows per column.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

Column order changes are announced; the focused cell stays visible when pinned columns are used.

## Troubleshooting

A profile restored on a grid with different columns returns warnings instead of failing; check them to see which saved columns no longer exist.
