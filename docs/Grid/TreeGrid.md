## Overview

Rows form a tree through ParentId. Expand and collapse nodes with the chevron or Alt+Right/Left; search expands the path to each match; summaries stay exact.

- Self-reference tree
- Expand to reveal search matches
- Cycle-safe
- Column summaries
- Sorting within levels

## Architecture notes

A self-reference relation turns flat rows into a tree. The engine builds the visible row list from parent keys, orders siblings by the active sort, keeps ancestors of filter matches, and detects cycles.

## Usage guide

grid.AddSelfReference("Id", "ParentId"); grid.TreeExpandedByDefault = true; grid.ExpandAllTreeNodes().

## Best practices

Use stable integer keys, index parent keys in your source, and expand lazily for large trees.

## Performance notes

The tree is built once per query in linear time; collapsed subtrees cost nothing to render.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

Tree rows announce level and expanded state; the chevron is also reachable with Alt+Right and Alt+Left.

## Troubleshooting

Rows with a missing parent appear at the root; cyclic parent chains are broken at the repeat instead of looping. Check ParentId values if nodes disappear.
