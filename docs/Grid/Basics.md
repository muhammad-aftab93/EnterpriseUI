## Architecture notes

EnterpriseDataGrid<T> is a thin GDI+ view over the headless DataGrid<T> engine. The engine owns data, query, selection and editing state; the control owns painting, input and UI Automation.

## Usage guide

Add GridColumn entries (Field, Title, Width, FormatString), assign DataSource, then optionally call RefreshDataAsync after external changes.

public static class GeneratedGridFluent
{
    public static EnterpriseDataGrid<GridDemoRecord> Create(IEnumerable<GridDemoRecord> data) =>
        GridBuilder<GridDemoRecord>.Create()

            .Column("Quantity", "Qty", 70d, c => { c.Alignment = ColumnTextAlignment.Right; })
            .Column("Total", "Gross Amount", 110d, c => { c.ReadOnly = true; c.Alignment = ColumnTextAlignment.Right; c.FormatString = "C2"; })
            .Column("Priority", "Priority", 90d, c => { c.ComboItems = new object[] { "Low", "Normal", "High", "Critical" }; })
            .Column("Status", "Status", 100d)
            .Column("Timestamp", "Date", 100d, c => { c.FormatString = "d"; })
            .Configure(g =>

            .Build();

## Best practices

Keep row height fixed, format values with FormatString and give the grid an AriaLabel.

## Performance notes

Only the rows near the viewport are materialized. Row height is fixed, so the first visible row, the scroll range and hit testing are computed arithmetically.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

The control exposes a Table > Row > Cell UI Automation tree, a visible focus ring and a keyboard model (arrows, Home/End, Page keys, F2, Space, Ctrl+A/C/Z/Y/F).

## Troubleshooting

Columns that show nothing usually name a property that does not exist: Field is matched to a public property of T (case-insensitive, dotted paths allowed). Call RefreshDataAsync after replacing items outside the grid.
