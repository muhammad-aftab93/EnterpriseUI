## Overview

Add and delete rows with undo, drag selected rows to reorder, or drag them into the second grid (Ctrl copies). Both grids share the same item type.

- Add row
- Delete rows
- Undo/redo
- Drag reorder
- Cross-grid drag and drop
- Row styling

## Architecture notes

Structural edits (add, remove, move, transfer) operate on the in-memory list behind the grid and are recorded as undoable entries. MoveRows rebuilds the order in one step so a multi-row drag is one undo.

## Usage guide

grid.AllowRowDrag = true; grid.AllowRowDrop = true; grid.AddRow(item); grid.RemoveRows(grid.SelectedItems); grid.MoveRows(items, before).

## Best practices

Use RowStyleNeeded for state-based colors instead of custom painting, confirm destructive deletes in the UI, and keep a visible undo.

## Performance notes

Moving rows rewrites the list once; for very large lists prefer data-source specific operations.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

Moves are announced ('Moved 3 rows'); every drag action also has a keyboard path through Delete, Ctrl+Z and the context menu.

## Troubleshooting

Drag and drop needs AllowRowDrag on the source and AllowRowDrop on the target, a list source (IList<T>), and the same item type in both grids.
