## Overview

Edit with F2, Enter or double-click. Required, range and regex rules reject bad values with a message; switch to popup or batch mode and commit or roll back.

- In-cell editing
- Popup/form editing
- Batch commit/rollback
- Validation rules
- Undo/redo
- Typed editors

## Architecture notes

Editing goes through DataGrid<T>.TryEditCell: convert, validate (column rules, then row rules), apply, record undo, raise events. The control only chooses an editor and shows the outcome.

## Usage guide

grid.EditMode = GridEditMode.Batch; column.ValidationRules.Add(new RangeRule(30000, 200000) { Message = "..." }); grid.CommitChanges() / RollbackChanges().

```csharp
public static class GeneratedGridFluent
{
    public static EnterpriseDataGrid<EmployeeRow> Create(IEnumerable<EmployeeRow> data) =>
        GridBuilder<EmployeeRow>.Create()
            .Label("Employees")
            .Column("Id", "ID", 60d, c => { c.ReadOnly = true; })
            .Column("Name", "Name", 170d, c => { c.ValidationRules.Add(new RequiredRule { Message = "Name is required" }); c.ValidationRules.Add(new LengthRule(2, 40) { Message = "Name must be 2 to 40 characters" }); })
            .Column("Email", "Email", 230d)
            .Column("Department", "Department", 120d, c => { c.ComboItems = new object[] { "Engineering", "Sales", "Finance", "Operations", "Support" }; })
            .Column("Salary", "Salary", 100d, c => { c.Alignment = ColumnTextAlignment.Right; c.FormatString = "C0"; c.FooterSummaries.Add(new GridColumnSummary(AggregateFunction.Average, "C0")); c.ValidationRules.Add(new RangeRule(30000m, 200000m) { Message = "Salary must be between 30,000 and 200,000" }); })
            .Column("Active", "Active", 70d)
            .Column("Hired", "Hired", 100d, c => { c.FormatString = "d"; })
            .Column("Rating", "Rating", 70d, c => { c.Alignment = ColumnTextAlignment.Right; c.ValidationRules.Add(new RangeRule(1, 5) { Message = "Rating is 1 to 5" }); })
            .Configure(g =>
                {
                    g.ShowGroupPanel = false;
                    g.ItemHeight = 28d;
                })
            .DataSource(data)
            .Build();
}

```

## Best practices

Put rules on columns, use Batch mode for review-and-save flows, show validation text next to the grid, and keep undo available.

## Performance notes

Validation runs per edited cell and per row; async rules run off the UI thread. Batch mode keeps a dictionary of pending changes instead of copying rows.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

Errors are announced assertively, shown as a marker plus text (not color alone) and exposed in the cell's accessible name.

## Troubleshooting

If an edit silently does nothing the column is ReadOnly, calculated, or EditMode is None. If an invalid value appears to be accepted, RejectInvalidEdits is false.
