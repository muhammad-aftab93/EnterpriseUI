## Overview

Type in the filter row, open the funnel in a header for a value list, or apply operator filters from the toolbar. Presets save and restore a whole filter set.

- Filter row
- Excel-style value list
- 18 operators
- Between
- Presets
- Search panel

## Architecture notes

Filters are descriptors (FilterDescriptor, CompositeFilterDescriptor, CustomFilterDescriptor) evaluated by the query engine. Value-list, filter-row and search-panel filters are all expressed as descriptors, so they combine and serialize.

## Usage guide

FilterBy(field, operator, value), SetQuickFilter(field, text), ApplyExcelFilter(field, values), SaveFilterPreset(name).

## Best practices

Save common filters as presets, show the filter row for power users, and combine the search panel with column filters instead of building custom text boxes.

## Performance notes

Filters compile to expression trees for in-memory sources and translate to OData-style requests for remote sources.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

Filtered headers are announced as 'filtered'; the status bar and live region report the matching row count.

## Troubleshooting

If a filter seems ignored check the column's FilterType and that the value type matches the property type (the engine converts strings but not arbitrary objects). Calculated columns filter through an in-memory predicate.
