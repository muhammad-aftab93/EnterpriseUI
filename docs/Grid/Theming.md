## Overview

Switch themes live. Every grid element (rows, selection, focus, search matches, errors, pager, summaries) takes its color from the theme tokens.

- Theme switch
- Dark schemes
- High contrast
- Token-derived selection/focus/error colors
- WCAG-corrected palette

## Architecture notes

Colors are tokens (#hex or rgba()) in the theme. GridPalette resolves them against the surface, then corrects text, indicators and selection to their contrast targets. The control converts the palette to Colors once per theme change.

## Usage guide

ThemeManager.Instance.ApplyTheme("Fluent-Dark"); var palette = GridPalette.FromTheme(ThemeManager.Instance.CurrentTheme);

## Best practices

Define tokens, not colors, in custom themes; test light, dark and high contrast; do not hard-code colors in format rules unless the contrast is verified.

## Performance notes

A theme change invalidates one cached palette object and repaints; no per-cell color lookups happen while painting.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

High contrast themes use the text color for borders and a solid primary for selection so state never depends on subtle tints.

## Troubleshooting

If a custom theme looks wrong run GridAccessibility.Audit(theme); low-contrast tokens are reported with their ratio. Missing tokens fall back to neutral defaults.
