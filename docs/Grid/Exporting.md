## Overview

Export every row matching the current query in a streaming pass with progress and cancel. Groups, summaries and conditional formatting carry into the file.

- xlsx
- csv
- pdf
- html
- json
- xml
- Group outline
- Summaries
- Conditional formatting
- Progress/cancel

## Architecture notes

Providers implement IExportProvider and receive rows one at a time, so memory stays flat for large exports; the service pumps progress and cancellation.

## Usage guide

await grid.ExportToFileAsync("report.xlsx", new GridExportOptions { IncludeGroups = true }); or grid.ExportWithDialogAsync("pdf").

## Best practices

Export from the grid so the file matches what users see, set a title, cap rows for PDF, and report progress for long exports.

## Performance notes

CSV and JSON stream with constant memory; xlsx writes worksheet XML directly without an intermediate workbook object.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

Progress and completion are announced; exported PDFs carry the document title and real text (not images).

## Troubleshooting

A CSV opened in Excel can run formulas; CsvSanitizeFormulas (on by default) prefixes dangerous cells so they stay text.
