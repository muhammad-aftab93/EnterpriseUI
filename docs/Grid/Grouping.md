## Overview

Group by one or more columns from the toolbar, the group panel or a header menu. Group headers show counts and aggregates; footers repeat the totals.

- Multi-level groups
- Group summaries
- Group footers
- Expand/collapse
- Group panel drag

## Architecture notes

Groups are computed over the whole filtered result and flattened into a row list of group headers, data rows and optional footers. Expansion state is keyed by group path so it survives refreshes.

## Usage guide

GroupBy(field), RemoveGroup(field), ExpandAllGroups(), GroupSummaries.Add(new GroupSummaryDescriptor(field, AggregateFunction.Sum, "{0:C0}")).

## Best practices

Limit grouping to two or three levels, set GroupsExpandedByDefault = false for big data, and use group summaries rather than computing totals in the UI.

## Performance notes

Grouping flattens the group tree into a row list once per query; collapsed groups cost no row rendering.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

Group rows expose level, expanded state and item count; Alt+Right and Alt+Left expand and collapse the focused group.

## Troubleshooting

If groups never show totals add GroupSummaries entries; if a group shows (blank) the key value is null. Group footers need ShowGroupFooters.
