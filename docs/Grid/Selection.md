## Overview

Pick a selection mode, then click, Shift+click, Ctrl+click or drag. Ctrl+A selects all, Ctrl+C copies with headers, arrow keys move the focus cell.

- Single/multiple rows
- Checkbox column
- Cell range
- Column selection
- Select all
- Clipboard copy

## Architecture notes

GridSelectionModel tracks rows, cell ranges and columns by display position and implements the mouse and keyboard gestures. The engine maps display rows to items for SelectedItems.

## Usage guide

grid.SelectionMode = GridSelectionMode.CellRange; grid.Selection.SelectAll(); grid.SelectedItems; grid.CopySelectionToClipboard().

## Best practices

Use CheckboxRow for bulk actions, CellRange for spreadsheet-like use, and read SelectedItems instead of indexes in application code.

## Performance notes

Selection stores row indexes and ranges, not item copies, so selecting a million rows is a range, not a million objects.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

The focus cell has a 2 px ring in every theme, selection never relies on color alone in high contrast, and selection changes are exposed through UI Automation.

## Troubleshooting

Selection resets when the query or page changes because display positions change; keep identity with SelectedItems before changing the query.
