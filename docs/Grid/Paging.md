## Overview

Switch between client paging, server-style paging, virtual scrolling and infinite load-more over 5,000 rows. The pager appears for paged modes.

## Architecture notes

Paging sits between the query result and the row window; sorting, filtering and grouping run over the full result before a page is cut.

## Usage guide

Set PagingMode and PageSize; use GoToPage, NextPage and PageChanged. Selection and detail expansion reset when the page changes.

## Best practices

Choose Server paging for remote or very large sources and keep PageSizeOptions small and meaningful.

## Performance notes

Client paging holds one query result; use Server or Virtual paging for sources too large to materialize.

Measured numbers are in [PerformanceReport](Reports/PerformanceReport.md).

## Accessibility notes

Pager buttons are drawn, so page changes are announced through the live region (Page 2 of 40). Ctrl+PageUp/PageDown change page from the keyboard.

## Troubleshooting

If a page shows fewer rows than PageSize the filtered result is shorter; if the pager is missing check PagingMode (None and Virtual have no pager) and ShowPager.
