# EnterpriseUI.Wpf

WPF platform integration package for EnterpriseUI desktop applications.

## What it provides

- WPF integration for EnterpriseUI components and shared services.
- Desktop application primitives that complement the platform-neutral libraries.
- Access to the EnterpriseUI theme, data, layout, and workflow ecosystem.

## Requirements

- .NET 8.0 or later.
- A WPF application targeting Windows.

## Installation

```powershell
dotnet add package EnterpriseUI.Wpf --version 1.2.0
```

NuGet restores the EnterpriseUI dependencies declared by this package. Configure the feed that contains the EnterpriseUI packages before restoring.
