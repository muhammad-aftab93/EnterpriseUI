# EnterpriseUI.AspNetCore

ASP.NET Core integration package for the EnterpriseUI platform.

## What it provides

- ASP.NET Core hosting and integration primitives for EnterpriseUI applications.
- A platform boundary for web applications that share EnterpriseUI models and services.
- Compatibility with the EnterpriseUI component ecosystem.

## Requirements

- .NET 8.0 or later.
- An ASP.NET Core application.

## Installation

```powershell
dotnet add package EnterpriseUI.AspNetCore --version 1.2.0
```

NuGet restores the EnterpriseUI dependencies declared by this package. Configure the feed that contains the EnterpriseUI packages before restoring.
