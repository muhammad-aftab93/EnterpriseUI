# EnterpriseUI.Blazor

Blazor integration package for building EnterpriseUI web experiences.

## What it provides

- Blazor platform integration for EnterpriseUI components and shared services.
- A web application boundary for reusable EnterpriseUI models and workflows.
- Access to the broader EnterpriseUI component ecosystem.

## Requirements

- .NET 8.0 or later.
- A Blazor application.

## Installation

```powershell
dotnet add package EnterpriseUI.Blazor --version 1.2.0
```

NuGet restores the EnterpriseUI dependencies declared by this package. Configure the feed that contains the EnterpriseUI packages before restoring.
