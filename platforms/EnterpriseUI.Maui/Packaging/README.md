# EnterpriseUI.Maui

.NET MAUI integration package for EnterpriseUI applications.

## What it provides

- A .NET MAUI platform boundary for EnterpriseUI components and shared services.
- Cross-platform application integration points.
- Compatibility with EnterpriseUI headless models and workflows.

## Requirements

- .NET 8.0 or later.
- A .NET MAUI application with the required platform workloads installed.

## Installation

```powershell
dotnet add package EnterpriseUI.Maui --version 1.2.0
```

NuGet restores the EnterpriseUI dependencies declared by this package. Configure the feed that contains the EnterpriseUI packages before restoring.
